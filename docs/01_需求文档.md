# 每周人社资讯生成器 — 需求文档

## 1. 项目概述

| 项目属性 | 说明 |
|---------|------|
| 项目名称 | 每周人社资讯生成器 |
| 目标用户 | 人社部门宣传工作人员 |
| 核心目标 | 自动化生成《每周人社资讯》四板块内容，减少人工编写工作量 |
| 技术架构 | FastAPI + SQLAlchemy(Async) + MySQL + Jinja2 + Bootstrap 5 |
| AI引擎 | DeepSeek API (V3/R1) |

## 2. 功能需求

### 2.1 新闻获取模块

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-001 | 系统从本地新闻API获取四类新闻数据：人社要闻、业务动态、舆论声音、省内动向 | P0 |
| F-002 | 新闻数据优先从本地缓存数据库读取，减少API调用 | P1 |
| F-003 | 支持按类别加载新闻，每次默认加载20条 | P1 |
| F-004 | 支持新闻标题关键词搜索过滤 | P1 |
| F-005 | 新闻列表支持分页展示，每页10条 | P1 |
| F-006 | 点击新闻标题可跳转查看原文 | P2 |

### 2.2 新闻选择模块

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-007 | 支持拖拽方式将新闻添加到四个板块区域 | P0 |
| F-008 | 支持点击"选择"按钮通过模态框选择目标板块 | P0 |
| F-009 | 同一新闻不能重复添加到同一板块 | P1 |
| F-010 | 新闻添加到新板块时自动从原板块移除 | P1 |
| F-011 | 支持从板块中移除已选新闻 | P1 |
| F-012 | 已选新闻在板块区域显示标题、来源、发布时间 | P1 |

### 2.3 AI内容生成模块

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-013 | 支持选择DeepSeek-V3或DeepSeek-R1模型 | P0 |
| F-014 | 按板块顺序逐一生成内容：人社要闻 → 业务动态 → 舆论声音 → 省内动向 | P0 |
| F-015 | 生成内容要求：以新闻播报者角度、单段落、400字左右、不少于300字 | P0 |
| F-016 | 生成内容自动包含新闻标题、来源、日期前缀和后缀 | P1 |
| F-017 | 生成过程中显示加载动画和进度提示 | P1 |
| F-018 | 生成内容自动保存到数据库 | P1 |

### 2.4 内容编辑模块

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-019 | 支持在文本框中编辑生成的内容 | P0 |
| F-020 | 支持保存编辑后的内容到数据库 | P0 |
| F-021 | 导出页面支持可视化预览和直接编辑 | P1 |
| F-022 | 编辑内容自动同步保存 | P1 |

### 2.5 文档导出模块

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-023 | 支持导出Word文档(.docx) | P0 |
| F-024 | 支持导出PDF文档(.pdf) | P0 |
| F-025 | 文档标题支持自定义 | P1 |
| F-026 | Word文档使用仿宋_GB2312正文、方正小标宋简体标题 | P0 |
| F-027 | PDF文档使用对应中文字体，支持首行缩进 | P0 |
| F-028 | 文档格式符合政府公文标准：标题居中22磅、正文16磅、行高28磅 | P0 |
| F-029 | 导出文件自动生成时间戳命名 | P1 |
| F-030 | 支持在线下载导出的文档 | P0 |

### 2.6 字体管理模块

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-031 | 系统内置仿宋_GB2312和方正小标宋简体字体文件 | P1 |
| F-032 | 提供字体文件下载入口 | P2 |

## 3. 非功能需求

### 3.1 性能需求
- 新闻API响应时间 ≤ 3秒
- AI生成单板块内容 ≤ 30秒
- 文档导出 ≤ 5秒
- 页面加载 ≤ 2秒

### 3.2 可靠性需求
- API调用失败时自动回退到数据库缓存数据
- 数据库连接异常时给出明确错误提示
- 文件导出失败时不残留临时文件

### 3.3 兼容性需求
- 支持 Chrome、Firefox、Edge 等现代浏览器
- 支持 Windows/Linux 服务器部署
- 支持 Docker 容器化部署

### 3.4 安全需求
- DeepSeek API Key 通过环境变量配置，不硬编码
- 数据库连接信息通过环境变量配置
- 字体下载接口限制只能下载允许的字体文件

## 4. 数据需求

### 4.1 新闻数据字段
| 字段名 | 类型 | 说明 |
|-------|------|------|
| 新闻标题 | String | 新闻标题，最长500字符 |
| 所属板块 | String | 人社要闻/业务动态/舆论声音/省内动向 |
| 发布时间 | String | 新闻发布日期 |
| 新闻来源 | String | 新闻来源网站/机构 |
| 新闻链接 | String | 原文URL，唯一标识 |
| 新闻内容 | Text | 网页原始内容(可选) |

### 4.2 生成内容数据字段
| 字段名 | 类型 | 说明 |
|-------|------|------|
| 板块分类 | String | 所属板块 |
| 生成内容 | Text | AI生成的完整文本 |
| 引用新闻 | JSON | 用于生成的新闻URL列表 |
| 使用模型 | String | deepseek-v3 / deepseek-r1 |
| 创建时间 | DateTime | 生成时间 |

## 5. 界面需求

### 5.1 页面结构
- **首页** (`/`)：左右布局，左侧新闻列表(8列)，右侧四个板块区域(4列)
- **生成页** (`/generate`)：单栏布局，显示当前板块、模型选择、新闻列表、生成内容编辑区
- **导出页** (`/export`)：单栏布局，标题输入、内容预览、导出按钮

### 5.2 交互需求
- 拖拽操作有视觉反馈(dragover高亮)
- 生成过程显示旋转加载动画
- 操作成功/失败有弹窗提示
- 板块切换有明确的当前状态指示

## 6. 部署需求

- 支持 `uvicorn` 直接运行
- 支持 Docker 容器化部署
- 依赖 MySQL 5.7+ 数据库
- 需要外部新闻API服务(端口4399)
