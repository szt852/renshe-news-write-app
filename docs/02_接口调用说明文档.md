# 每周人社资讯生成器 — 接口调用说明文档

## 基础信息

| 项目 | 说明 |
|-----|------|
| 基础URL | `http://localhost:8000` (默认) |
| 接口风格 | RESTful + Form Data |
| 响应格式 | JSON |
| 认证方式 | 无 (本地服务) |

---

## 1. 页面路由

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 首页 — 新闻浏览与选择 |
| GET | `/generate` | 生成页 — AI内容生成与编辑 |
| GET | `/export` | 导出页 — 内容预览与文档导出 |

---

## 2. 新闻相关接口

### 2.1 获取新闻列表

```http
GET /api/news/{category}?news_count={count}
```

**路径参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| category | string | 是 | 板块标识：`rensheyaowen`/`yewudongtai`/`yvlunshengying`/`shengneidongxiang` |

**查询参数：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|-----|------|------|--------|------|
| news_count | int | 否 | 5 | 获取新闻数量 |

**响应示例：**

```json
{
  "result_str": "从数据库查询到新闻数据 5 条！",
  "result": [
    {
      "新闻标题": "人社部举办2024年高校毕业生就业服务专项行动",
      "所属板块": "rensheyaowen",
      "发布时间": "2024-12-01",
      "新闻来源": "人社部官网",
      "新闻链接": "http://www.mohrss.gov.cn/xx/202412/t20241201_123456.html"
    }
  ]
}
```

**业务逻辑：**
1. 优先查询本地数据库缓存
2. 数据库数据不足时，调用外部API获取并入库
3. API调用失败时，回退返回数据库已有数据

---

## 3. 内容生成接口

### 3.1 生成板块内容

```http
POST /api/generate
```

**请求体 (application/x-www-form-urlencoded)：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| category | string | 是 | 板块标识 |
| news_urls | string | 是 | 新闻URL列表，逗号分隔 |
| model | string | 否 | `deepseek-v3`(默认) / `deepseek-r1` |

**响应示例：**

```json
{
  "id": 1,
  "content": "【人社要闻】\n    1.人社部举办2024年高校毕业生就业服务专项行动。为贯彻党中央...（来源：人社部官网  2024年12月01日）\n"
}
```

**业务逻辑：**
1. 根据URL从数据库读取新闻信息
2. 构建包含文风示例的Prompt
3. 调用DeepSeek API生成内容
4. 自动拼接标题前缀和来源后缀
5. 保存到数据库并返回

---

### 3.2 保存生成的内容

```http
POST /api/save_content/{content_id}
```

**路径参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| content_id | int | 是 | 内容记录ID |

**请求体 (application/x-www-form-urlencoded)：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| content | string | 是 | 编辑后的完整内容 |

**响应示例：**

```json
{
  "status": "success"
}
```

---

### 3.3 获取生成内容（批量）


**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| content_ids | string | 是 | 内容ID列表，逗号分隔 |

**响应示例：**

## 4. 文档导出接口

### 4.1 导出报告

```http
POST /api/export
```

**请求体 (application/x-www-form-urlencoded)：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| title | string | 是 | 文档标题 |
| content_ids | string | 是 | 内容ID列表，逗号分隔 |
| format | string | 否 | `word`(默认) / `pdf` |

**响应示例：**

```json
{
  "filename": "每周人社资讯_20241201_143052.docx",
  "filepath": "exports/每周人社资讯_20241201_143052.docx",
  "format": "word"
}
```

**业务逻辑：**
1. 查询数据库获取最新内容
2. 按板块顺序合并内容
3. 创建WeeklyReport记录
4. 根据格式生成Word或PDF文档
5. 使用仿宋_GB2312和方正小标宋简体字体

---

### 4.2 下载文件

```http
GET /download/{filename}
```

**路径参数：**

| 参数 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| filename | string | 是 | 导出文件名 |

**响应：** 文件流，Content-Type根据扩展名自动设置

## 6. 前端页面交互流程

```
┌─────────┐    选择新闻     ┌──────────┐    生成内容     ┌─────────┐    导出文档     ┌─────────┐
│  首页   │ ─────────────→ │  生成页  │ ─────────────→ │  导出页 │ ─────────────→ │ 下载文件│
│   /     │  sessionStorage │ /generate│  sessionStorage│ /export │   POST /api/    │         │
└─────────┘                └──────────┘                └─────────┘   export        └─────────┘
     │                          │                          │
     │ GET /api/news/{cat}      │ POST /api/generate       │ GET /api/get_generated_contents
     │                          │ POST /api/save_content   │ POST /api/export
     │                          │ GET /api/get_news_info   │ GET /download/{filename}
     ▼                          ▼                          ▼
```

---

## 7. 错误码说明

| HTTP状态码 | 说明 |
|-----------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误（如ID格式不正确） |
| 404 | 资源不存在（新闻、内容、文件未找到） |
| 500 | 服务器内部错误（API调用失败、数据库错误等） |

## 8. 外部依赖接口

系统运行依赖的外部新闻API（需在 `run_ip:4399` 提供服务）：

| 接口 | 说明 |
|------|------|
| `GET http://{run_ip}:4399/get_rensheyaowen_news` | 获取人社要闻 |
| `GET http://{run_ip}:4399/get_yewudongtai_news` | 获取业务动态 |
| `GET http://{run_ip}:4399/get_yvlunshengying_news` | 获取舆论声音 |
| `GET http://{run_ip}:4399/get_shengneidongxiang_news` | 获取省内动向 |

**请求参数：** `news_count` (int)

**响应格式：** 与 `/api/news/{category}` 相同

## 9. DeepSeek API 调用

系统内部调用 DeepSeek API 进行内容生成：

```http
POST https://api.deepseek.com/chat/completions
```

**请求头：**
```
Authorization: Bearer {DEEPSEEK_API_KEY}
Content-Type: application/json
```

**请求体：**
```json
{
  "model": "deepseek-chat",
  "messages": [
    {
      "role": "system",
      "content": "你是一个专业的人社资讯撰写专家..."
    },
    {
      "role": "user",
      "content": "Prompt内容..."
    }
  ],
  "temperature": 0.7,
  "max_tokens": 200,
  "stream": false
}
```
