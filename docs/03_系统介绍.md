# 每周人社资讯生成器 — 系统介绍

## 一、系统定位

**每周人社资讯生成器**是一款面向人力资源和社会保障部门的智能化资讯生产工具。系统通过整合AI大模型能力，将原本需要数小时人工编写的人社周报工作压缩至分钟级完成，显著提升政务宣传工作效率。

## 二、核心业务场景

人社部门每周需要发布《每周人社资讯》，内容涵盖四大板块：

| 板块 | 内容定位 |
|-----|---------|
| **人社要闻** | 人社部及国家层面的重要政策、会议、活动 |
| **业务动态** | 各地人社部门的业务创新、服务举措 |
| **舆论声音** | 媒体对人社工作的报道和评价 |
| **省内动向** | 本省人社领域的重要动态 |

传统工作模式下，工作人员需要：
1. 浏览数十个网站收集新闻
2. 筛选有价值的信息
3. 人工编写各板块内容
4. 排版成规范的公文格式

本系统将此流程全面自动化。

## 五、数据模型

### 5.1 新闻条目 (news_items)

存储从外部API获取的新闻数据，作为本地缓存。

```
┌─────────────┬──────────────┬─────────────────────────────┐
│ 字段名      │ 类型         │ 说明                        │
├─────────────┼──────────────┼─────────────────────────────┤
│ id          │ Integer(PK)  │ 自增主键                    │
│ title       │ String(500)  │ 新闻标题，建立索引          │
│ category    │ String(100)  │ 所属板块，建立索引          │
│ publish_date│ String(100)  │ 发布日期                    │
│ source      │ String(200)  │ 新闻来源                    │
│ url         │ String(500)  │ 原文链接，唯一标识          │
│ content     │ Text         │ 网页内容(可选)              │
│ created_at  │ DateTime     │ 入库时间                    │
└─────────────┴──────────────┴─────────────────────────────┘
```

### 5.2 生成内容 (generated_contents)

存储AI生成的各板块资讯内容。

```
┌─────────────┬──────────────┬─────────────────────────────┐
│ 字段名      │ 类型         │ 说明                        │
├─────────────┼──────────────┼─────────────────────────────┤
│ id          │ Integer(PK)  │ 自增主键                    │
│ category    │ String(100)  │ 板块标识，建立索引          │
│ content     │ Text         │ 生成的完整文本              │
│ news_items  │ JSON         │ 引用的新闻URL列表           │
│ model_used  │ String(100)  │ 使用的AI模型                │
│ created_at  │ DateTime     │ 创建时间                    │
│ updated_at  │ DateTime     │ 最后更新时间                │
└─────────────┴──────────────┴─────────────────────────────┘
```

### 5.3 周报记录 (weekly_reports)

存储最终导出的周报元数据。

```
┌─────────────────┬──────────────┬─────────────────────────────┐
│ 字段名          │ 类型         │ 说明                        │
├─────────────────┼──────────────┼─────────────────────────────┤
│ id              │ Integer(PK)  │ 自增主键                    │
│ title           │ String(200)  │ 周报标题                    │
│ content         │ Text         │ 合并后的完整内容            │
│ generated_contents│ JSON       │ 各板块内容ID列表            │
│ created_at      │ DateTime     │ 创建时间                    │
│ export_path     │ String(500)  │ 导出文件路径                │
└─────────────────┴──────────────┴─────────────────────────────┘
```

## 六、特色功能

### 6.1 智能内容生成

系统内置专业Prompt工程，确保生成内容符合政府公文风格：

- **角色设定**：专业人社资讯撰写专家
- **文风示例**：提供标准公文段落作为参考
- **格式约束**：单段落、400字左右、不少于300字
- **自动封装**：自动添加序号标题前缀和来源日期后缀

### 6.2 公文级排版输出

导出文档严格遵循政府公文格式规范：

| 格式要素 | 设置 |
|---------|------|
| 标题字体 | 方正小标宋简体，22磅 |
| 正文字体 | 仿宋_GB2312，16磅 |
| 行高 | 28磅 |
| 标题对齐 | 居中 |
| 正文对齐 | 两端对齐，首行缩进 |

### 6.3 双缓存机制

- **数据库缓存**：新闻数据持久化存储，减少外部API调用
- **降级策略**：外部API失败时自动返回数据库缓存数据

### 6.4 灵活的新闻选择

支持两种操作方式：
- **拖拽操作**：直接从新闻列表拖拽到目标板块
- **点击选择**：通过模态框选择目标板块

## 七、部署方式

### 方式一：直接运行
```bash
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 方式二：Docker部署
```bash
docker-compose up -d
```

- Python 3.8+
- MySQL 5.7+
