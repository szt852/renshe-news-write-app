# 每周人社资讯生成器 — 操作说明

## 一、准备工作

### 1.1 环境检查清单

在开始使用前，请确认以下服务已就绪：

- [ ] MySQL数据库已启动，且已创建 `aitools` 数据库
- [ ] 外部新闻API服务已启动（端口4399）
- [ ] 已配置 `.env` 文件，包含 `DEEPSEEK_API_KEY`
- [ ] 系统依赖已安装：`pip install -r requirements.txt`
- [ ] `fonts/` 目录下包含中文字体文件：`仿宋_GB2312.TTF`、`方正小标宋简体.TTF`

### 1.2 启动系统

```bash
# 方式一：直接启动
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# 方式二：Docker启动
docker-compose up -d
```

启动成功后，在浏览器访问：`http://localhost:8000`

### 2.2 加载新闻

1. 在页面左上角，从下拉框选择要查看的板块：
   - 人社要闻
   - 业务动态
   - 舆论声音
   - 省内动向

2. 点击 **「加载新闻」** 按钮

3. 系统会显示该板块的最近20条新闻

> **提示**：如果数据库中已有缓存数据，会优先显示缓存；否则会自动从外部API获取。

### 2.3 搜索新闻

在搜索框输入关键词，系统会实时过滤新闻标题，高亮匹配结果。

### 2.4 选择新闻到板块

**方法一：拖拽选择**

1. 在左侧新闻列表中，按住鼠标左键拖拽新闻行
2. 拖动到右侧对应的板块区域（会出现高亮边框）
3. 松开鼠标，新闻即添加到该板块

**方法二：点击选择**

1. 在新闻行右侧点击 **「选择」** 按钮
2. 弹出模态框，选择目标板块
3. 新闻自动添加到所选板块

### 2.5 管理已选新闻

- **查看**：已选新闻显示在右侧对应板块的卡片中，包含标题、来源、时间
- **移除**：点击已选新闻右上角的 **×** 按钮，可从板块中移除
- **防重复**：同一新闻不能重复添加到同一板块；添加到新板块会自动从原板块移除

### 2.6 进入生成页面

四个板块中至少有一个包含新闻时，点击右下角的 **「一键生成」** 按钮，进入生成页面。

### 3.2 选择AI模型

在「选择模型」下拉框中选择：
- **DeepSeek-V3**：通用能力强，适合大多数场景
- **DeepSeek-R1**：推理能力强，适合需要深度分析的内容

### 3.3 生成内容

1. 确认当前板块和关联的新闻列表
2. 点击 **「生成内容」** 按钮
3. 等待AI生成（约10-30秒，显示加载动画）
4. 生成内容显示在下方的文本框中

> **注意**：生成内容自动包含格式：`序号.标题。正文内容（来源：xxx  日期）`

### 3.4 编辑内容

直接在文本框中修改生成的内容：
- 可增删文字
- 可调整语序
- 可补充信息

### 3.5 保存内容

编辑完成后，点击 **「保存内容」** 按钮，系统会将修改后的内容保存到数据库。

> **重要**：每个板块生成后建议先保存，再进入下一个板块。

### 3.6 切换板块

点击 **「下一个板块」** 按钮，系统自动切换到下一个有新闻的板块。

切换顺序固定为：**人社要闻 → 业务动态 → 舆论声音 → 省内动向**

### 3.7 完成所有板块

当所有包含新闻的板块都生成完成后，点击「下一个板块」会自动跳转到 **导出页面**。

在「资讯标题」输入框中可自定义文档标题，默认为「每周人社资讯」。

页面中部显示所有板块生成的内容，支持直接点击编辑：
- 点击任意板块内容即可修改
- 修改内容自动同步保存到数据库
- 无需手动点击保存按钮

### 4.4 导出Word文档

1. 点击 **「导出Word文档」** 按钮
2. 系统生成 `.docx` 文件
3. 浏览器自动触发下载
4. 文件保存在本地 `exports/` 目录

**Word文档格式：**
- 标题：方正小标宋简体，22磅，居中
- 正文：仿宋_GB2312，16磅
- 行高：28磅

### 4.5 导出PDF文档

1. 点击 **「导出PDF」** 按钮
2. 系统生成 `.pdf` 文件
3. 浏览器自动触发下载

**PDF文档格式：**
- 与Word保持一致的字体和排版
- 适合直接打印或电子传阅

### 4.6 导出文件命名规则

```
每周人社资讯_YYYYMMDD_HHMMSS.docx
每周人社资讯_YYYYMMDD_HHMMSS.pdf
```

例如：`每周人社资讯_20241201_143052.docx`

## 六、常见问题处理

### Q1: 加载新闻失败，提示API错误？

**可能原因**：
- 外部新闻API服务未启动
- 网络连接异常

**解决方法**：
1. 检查端口4399的服务是否正常运行
2. 查看系统是否已缓存该板块新闻（数据库有数据时会回退显示）

### Q2: 点击生成后长时间无响应？

**可能原因**：
- DeepSeek API服务繁忙
- 网络超时

**解决方法**：
1. 等待60秒后如仍无响应，刷新页面重试
2. 检查 `DEEPSEEK_API_KEY` 是否配置正确
3. 可尝试切换模型（V3/R1）

### Q3: 导出文档中文显示为方框或乱码？

**可能原因**：
- 系统缺少中文字体
- 字体文件未正确放置

**解决方法**：
1. 确认 `fonts/` 目录下有 `仿宋_GB2312.TTF` 和 `方正小标宋简体.TTF`
2. 通过顶部导航栏「下载字体」下载并安装到本机
3. 重新导出文档

### Q4: 如何清空已选新闻重新开始？

**解决方法**：
- 在生成页面或导出页面点击 **「返回重新选择」** 按钮
- 这会清空所有选择和生成记录，回到首页

### Q5: 数据库连接失败？

**可能原因**：
- MySQL未启动
- 数据库连接配置错误

**解决方法**：
1. 检查MySQL服务状态
2. 确认 `database.py` 中的连接URL正确
3. 确认数据库 `aitools` 已创建

## 八、注意事项

1. **及时保存**：每个板块生成后建议立即保存，避免意外刷新导致内容丢失
2. **模型选择**：日常资讯推荐DeepSeek-V3，政策解读类可尝试DeepSeek-R1
3. **内容审核**：AI生成内容仅供参考，发布前务必人工审核
4. **网络稳定**：生成过程需要调用外部API，请确保网络连接稳定
5. **定期清理**：`exports/` 目录会积累导出文件，建议定期清理
