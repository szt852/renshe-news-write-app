## 二、运行时调用的云端/远程 API 服务

### 2.1 已接入的模型服务

| 服务 | 端点地址 | 类型 | 用途 | 认证方式 |
|------|---------|------|------|---------|
| **DeepSeek API** | `https://api.deepseek.com/v1/chat/completions` | 云端 | AI 内容生成（可选） | Bearer Token（用户输入 API Key） |
| **Qwen3 API** | `http://10.27.51.1:80/ai/v1/chat/completions` | 内网/本地 | AI 内容生成（默认） | Bearer Token（内置默认 Key） |

### 2.2 内部依赖服务

| 服务 | 端点地址 | 类型 | 用途 | 说明 |
|------|---------|------|------|------|
| **新闻采集服务** | `http://127.0.0.1:4399` | 本地/内网 | 获取四类新闻数据 | 必须独立部署，提供 4 个接口 |
| **MySQL 数据库** | `127.0.0.1:3306` | 本地/内网 | 数据持久化存储 | 可用本地 MySQL 或云端 RDS |

### 2.3 新闻采集服务具体接口

新闻采集服务需在 `127.0.0.1:4399`（或 `run_ip:4399`）提供以下接口：

```
GET /get_rensheyaowen_news?news_count={n}     ← 人社要闻
GET /get_yewudongtai_news?news_count={n}      ← 业务动态
GET /get_yvlunshengying_news?news_count={n}   ← 舆论声音
GET /get_shengneidongxiang_news?news_count={n} ← 省内动向
```

> ⚠️ **注意**：若将新闻采集服务部署到云端，需同步修改 `main.py` 中的 `run_ip` 变量。

## 七、成本与网络依赖总结

| 资源类型 | 是否必须联网 | 是否产生费用 | 备注 |
|---------|------------|------------|------|
| PyPI 依赖安装 | 是（首次） | 否 | 免费开源包 |
| DeepSeek API | 调用时 | 是（按 token 计费） | 用户自付或单位统一采购 |
| Qwen3 API | 调用时 | 否（内网部署） | 本地/内网服务，无公网流量费 |
| 新闻采集服务 | 调用时 | 否（内网部署） | 需确保服务可用 |
| MySQL 数据库 | 运行时 | 否（本地）/ 是（云端 RDS） | 本地免费，云端按实例计费 |
| Docker 镜像 | 构建时 | 否 | Docker Hub 官方镜像免费 |
| 前端 CDN（可选） | 页面加载时 | 否 | jsDelivr CDN 免费 |
