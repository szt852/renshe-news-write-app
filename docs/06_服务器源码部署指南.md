# 每周人社资讯生成器 — 服务器源码部署指南

> 本文档指导你在 Linux 服务器（CentOS/Ubuntu）上从零开始源码部署本项目。

---

## 一、环境准备

### 1.1 服务器要求

| 项目 | 最低配置 | 推荐配置 |
|-----|---------|---------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB | 50 GB |
| 网络 | 内网互通 | 公网可访问 |
| 操作系统 | CentOS 7+ / Ubuntu 20.04+ | Ubuntu 22.04 LTS |

### 1.2 前置依赖安装

#### Python 3.10+

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y python3.10 python3.10-venv python3.10-dev python3-pip

# CentOS / RHEL（需先启用 EPEL 和 Software Collections）
sudo yum install -y centos-release-scl
sudo yum install -y rh-python310
scl enable rh-python310 bash
```

验证安装：
```bash
python3 --version   # 应显示 Python 3.10.x 或更高
pip3 --version
```

#### MySQL 5.7+

```bash
# Ubuntu
sudo apt install -y mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql

# CentOS
sudo yum install -y mysql-server
sudo systemctl start mysqld
sudo systemctl enable mysqld
```

#### Git（用于拉取代码）

```bash
# Ubuntu
sudo apt install -y git

# CentOS
sudo yum install -y git
```

## 二、数据库初始化

### 2.1 登录 MySQL 并创建数据库

```bash
sudo mysql -u root -p
```

在 MySQL 命令行中执行：

```sql
-- 创建数据库
CREATE DATABASE aitools CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建专用用户（建议不要用 root）
CREATE USER 'renshe'@'localhost' IDENTIFIED BY 'YourStrongPassword123!';
GRANT ALL PRIVILEGES ON aitools.* TO 'renshe'@'localhost';
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

> 💡 **提示**：如果是本地开发测试，可以直接用 root 用户，密码对应 `.env` 中的 `DATABASE_URL`。

## 三、项目部署

### 3.1 创建项目目录并拉取代码

```bash
# 创建应用目录
sudo mkdir -p /opt/renshe-news
sudo chown $USER:$USER /opt/renshe-news
cd /opt/renshe-news

# 拉取代码（替换为你的仓库地址）
git clone https://github.com/your-org/renshe-news-write-app.git .

# 或本地上传：通过 scp / rsync / FTP 将项目文件上传到该目录
```

### 3.2 创建 Python 虚拟环境

```bash
cd /opt/renshe-news

# 创建虚拟环境
python3 -m venv .venv

# 激活虚拟环境（后续所有 pip/python 命令都需在虚拟环境中执行）
source .venv/bin/activate

# 验证虚拟环境已激活
which python   # 应输出 /opt/renshe-news/.venv/bin/python
```

> ⚠️ **注意**：CentOS 下如果 `python3 -m venv` 报错，先执行 `pip3 install virtualenv`，再用 `virtualenv .venv`。

### 3.3 安装 Python 依赖

```bash
# 确保在虚拟环境中
source .venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装项目依赖
pip install -r requirements.txt
```

安装完成后验证关键包：
```bash
python -c "import fastapi; import sqlalchemy; import httpx; print('核心依赖安装成功')"
```

### 3.4 配置环境变量

```bash
cd /opt/renshe-news

# 复制模板文件
cp .env.example .env

# 编辑配置文件
nano .env
```

按实际环境修改以下内容：

```ini
# ============================================
# 必改项
# ============================================

# MySQL 数据库连接（替换为你的用户名、密码、数据库名）
DATABASE_URL=mysql+asyncmy://renshe:YourStrongPassword123!@127.0.0.1:3306/aitools

# 新闻采集服务地址
# 如果新闻采集服务和本项目在同一台服务器，保持 127.0.0.1
# 如果在其他服务器，改为对应 IP（如 192.168.1.100）
NEWS_API_HOST=127.0.0.1

# ============================================
# 选改项（AI 模型配置）
# ============================================

# Qwen3 本地模型（默认使用，一般无需修改）
QWEN3_API_URL=http://10.27.51.1:80/ai/v1/chat/completions
QWEN3_API_KEY=sk-ZKR2024@.com
QWEN3_MODEL_NAME=qwen3

# DeepSeek 云端模型（可选，管理员可预配默认 Key）
# DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
DEEPSEEK_API_URL=https://api.deepseek.com/v1/chat/completions
DEEPSEEK_MODEL_NAME=deepseek-chat
```

保存退出（`Ctrl+O` → `Enter` → `Ctrl+X`）。

### 3.5 准备字体文件

确保 `fonts/` 目录下有以下两个字体文件：

```bash
ls -la /opt/renshe-news/fonts/
# 应输出：
# 仿宋_GB2312.TTF
# 方正小标宋简体.TTF
```

如果缺少字体文件：
1. 从开发机器复制到 `fonts/` 目录
2. 或通过顶部导航栏下载后上传

### 3.6 准备导出目录

```bash
mkdir -p /opt/renshe-news/exports
```

### 3.7 初始化数据库表结构

```bash
cd /opt/renshe-news
source .venv/bin/activate

# 启动 Python 交互式环境执行建表
python -c "
import asyncio
from database import engine, Base

async def init():
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
    print('数据库表初始化完成')

asyncio.run(init())
"
```

> 💡 这一步会自动创建 `news_items`、`generated_contents`、`weekly_reports` 三张表。

## 四、启动应用

### 4.1 方式一：直接启动（调试/测试）

```bash
cd /opt/renshe-news
source .venv/bin/activate

# 前台启动，关闭终端后服务停止
uvicorn main:app --host 0.0.0.0 --port 8000
```

在浏览器访问：`http://服务器IP:8000`

> 按 `Ctrl+C` 停止服务。

### 4.2 方式二：后台启动（生产环境临时方案）

```bash
cd /opt/renshe-news
source .venv/bin/activate

# 后台运行，输出日志到 app.log
nohup uvicorn main:app --host 0.0.0.0 --port 8000 > app.log 2>&1 &

# 查看进程
ps aux | grep uvicorn

# 查看日志
tail -f app.log

# 停止服务
kill $(pgrep -f "uvicorn main:app")
```

### 4.3 方式三：systemd 守护进程（推荐生产方案）

创建 systemd 服务文件：

```bash
sudo nano /etc/systemd/system/renshe-news.service
```

写入以下内容：

```ini
[Unit]
Description=每周人社资讯生成器
After=network.target mysql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/renshe-news
Environment="PATH=/opt/renshe-news/.venv/bin"
EnvironmentFile=/opt/renshe-news/.env
ExecStart=/opt/renshe-news/.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

> 如果系统中没有 `www-data` 用户，可替换为 `root` 或创建专用用户：
> ```bash
> sudo useradd -r -s /bin/false renshe
> sudo chown -R renshe:renshe /opt/renshe-news
> ```

启动并启用服务：

```bash
# 重载 systemd 配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start renshe-news

# 设置开机自启
sudo systemctl enable renshe-news

# 查看运行状态
sudo systemctl status renshe-news

# 查看实时日志
sudo journalctl -u renshe-news -f
```

常用管理命令：
```bash
sudo systemctl start renshe-news    # 启动
sudo systemctl stop renshe-news     # 停止
sudo systemctl restart renshe-news  # 重启
sudo systemctl status renshe-news   # 查看状态
```

## 五、配置 Nginx 反向代理（可选但推荐）

如果需要通过域名访问，或配置 HTTPS，建议用 Nginx 做反向代理。

### 5.1 安装 Nginx

```bash
# Ubuntu
sudo apt install -y nginx

# CentOS
sudo yum install -y nginx
sudo systemctl start nginx
```

### 5.2 配置站点

```bash
sudo nano /etc/nginx/sites-available/renshe-news
```

写入配置：

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名或服务器 IP

    # 静态文件直接由 Nginx 处理（提升性能）
    location /static/ {
        alias /opt/renshe-news/static/;
        expires 30d;
    }

    # 字体文件
    location /fonts/ {
        alias /opt/renshe-news/fonts/;
        expires 30d;
    }

    # 导出文件下载
    location /exports/ {
        alias /opt/renshe-news/exports/;
    }

    # 其他请求转发到 Uvicorn
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置：

```bash
# Ubuntu
sudo ln -s /etc/nginx/sites-available/renshe-news /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# CentOS
sudo ln -s /etc/nginx/conf.d/renshe-news.conf /etc/nginx/conf.d/
sudo nginx -t
sudo systemctl reload nginx
```

### 5.3 配置 HTTPS（Let's Encrypt 免费证书）

```bash
# Ubuntu
sudo apt install -y certbot python3-certbot-nginx

# 申请并自动配置证书
sudo certbot --nginx -d your-domain.com

# 测试自动续期
sudo certbot renew --dry-run
```

## 七、常见问题

### Q1: 启动时报 `ModuleNotFoundError`

**原因**：未激活虚拟环境，或依赖未安装完整。  
**解决**：
```bash
cd /opt/renshe-news
source .venv/bin/activate
pip install -r requirements.txt
```

### Q2: 数据库连接失败 `Can't connect to MySQL`

**原因**：MySQL 未启动，或用户名/密码错误，或数据库未创建。  
**解决**：
```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 检查数据库是否存在
mysql -u root -p -e "SHOW DATABASES;"

# 检查 .env 中的 DATABASE_URL 配置是否正确
```

### Q3: 加载新闻失败

**原因**：新闻采集服务（端口 4399）未启动，或 `NEWS_API_HOST` 配置错误。  
**解决**：
```bash
# 检查新闻采集服务是否运行
curl http://127.0.0.1:4399/get_rensheyaowen_news?news_count=1

# 若服务在其他机器，修改 .env 中的 NEWS_API_HOST
```

### Q4: 生成内容时报 `网络请求错误`

**原因**：
- 若使用 Qwen3：内网地址 `10.27.51.1` 不可达
- 若使用 DeepSeek：API Key 无效或网络不通

**解决**：检查 `.env` 中的模型配置，或在前端页面直接输入有效的 DeepSeek API Key。

### Q5: 导出文档中文显示为方框

**原因**：服务器缺少中文字体。  
**解决**：确保 `fonts/` 目录下有 `仿宋_GB2312.TTF` 和 `方正小标宋简体.TTF`，重启服务后重试。
