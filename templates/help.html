使用帮助

了解数据来源、系统功能和操作流程，快速上手《每周人社资讯》生成

三步快速上手
1
选择新闻

浏览新闻列表，将感兴趣的新闻拖拽或点击选择到右侧四个板块中

2
AI 生成内容

选择模型（本地 Qwen3 或云端 DeepSeek），一键生成各板块资讯内容

3
导出文档

预览并编辑内容，导出符合公文格式的 Word 或 PDF 文档

数据来源

系统从内部新闻采集服务实时获取以下四个板块的新闻数据：

  • 人社要闻 人社部及国家层面的重要政策、会议、活动
  • 业务动态 各地人社部门的业务创新与服务举措
  • 舆论声音 主流媒体对人社工作的报道与评价
  • 省内动向 本省人社领域的重要动态与举措
新闻数据会自动缓存到本地数据库，API 不可用时优先使用缓存数据。
系统功能
  • 新闻浏览与搜索
    按板块加载新闻，支持标题关键词实时过滤
  • 拖拽 / 点击选择
    支持拖拽新闻到板块，或点击按钮选择目标板块
  • AI 智能生成
    内置专业 Prompt，生成符合政府公文风格的资讯
  • 双模型支持
    默认本地 Qwen3（免 Key）；可选云端 DeepSeek（需 API Key）
  • 在线编辑
    生成内容支持人工修改、微调，修改自动保存
  • 公文格式导出
    一键导出 Word / PDF，内置仿宋_GB2312、方正小标宋简体
如何操作

  1. 左上角下拉框选择板块，点击「加载新闻」
  2. 可输入关键词搜索过滤新闻标题
  3. 拖拽新闻到右侧板块，或点击「选择」按钮
  4. 点击新闻标题可查看原文（新标签页打开）
  5. 点击已选新闻的 × 可移除
  6. 至少选择一个板块后，点击「一键生成」

  1. 选择模型：默认「Qwen3 (本地)」无需配置；选「DeepSeek (云端)」需输入 API Key
  2. 点击「生成内容」，等待 AI 返回结果（约 10~30 秒）
  3. 在文本框中编辑生成的内容
  4. 点击「保存内容」将修改写入数据库
  5. 点击「下一个板块」继续生成其他板块
  6. 全部完成后自动进入导出页

  1. 可修改资讯标题（如「第X期每周人社资讯」）
  2. 在预览区直接点击编辑各板块内容，修改自动保存
  3. 点击「导出Word文档」或「导出PDF」
  4. 浏览器自动下载，文件保存在 exports/ 目录
  5. 如需重新选择新闻，点击「返回重新选择」
使用小贴士
  • 每个板块生成后建议先保存，再进入下一个板块
  • AI 生成内容仅供参考，发布前务必人工审核
  • 生成过程需调用外部 API，请确保网络连接稳定
  • DeepSeek API Key 仅用于当前会话，不会保存到服务器
  • 如遇问题，可尝试刷新页面或返回首页重新操作
导出文档中文显示异常？点击查看 Windows 字体安装方法

1. 下载字体文件

点击顶部导航栏 「下载字体 ▼」，分别下载 仿宋_GB2312 和 方正小标宋简体 两个字体文件（.TTF 格式）。

2. 安装字体（Windows 系统）

  1. 打开下载文件夹，找到下载好的 仿宋_GB2312.TTF 和 方正小标宋简体.TTF 文件。
  2. 方法一（推荐）：选中字体文件 → 点击鼠标右键 → 选择 「为所有用户安装」（Windows 10/11）或 「安装」（Windows 7/8）。
  3. 方法二：同时按 Win + R 键，输入 fonts 回车，打开字体文件夹 → 将下载的 .TTF 文件拖拽进去即可。
  4. 安装完成后，重启本系统（或刷新页面），重新导出文档即可正常显示。

3. 验证安装

打开 Word 或 WPS → 点击字体下拉框 → 搜索 "仿宋_GB2312"，如果能找到说明安装成功。
